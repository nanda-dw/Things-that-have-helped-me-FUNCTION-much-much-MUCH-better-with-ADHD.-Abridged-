# Things-that-have-helped-me-FUNCTION-much-much-MUCH-better-with-ADHD.-Abridged-
Compilation of everything that has significantly helped me in managing my ADHD. Covering useful resources I found, how I approached building routine and make it stick, tools I used, how i handle procrastination, manage working memory, how to juggle making multiple changes and a bunch of other stuff. Everything is kinda interrelated, but you can just pick and choose which section seems most relevant.

It's meant to be viewed in HTML format in your internet browser, but if that doesn't work I've included a PDF version too.

P.S enable dark mode on top right when using the HTML version.
